## 2024-05-24 - [Optimize heavy text parsing with substring and global regexes]
**Learning:** For heavy text parsing tasks like LaTeX section extraction, using a single-pass global regular expression (e.g., `/pattern/g` with `matchAll` or a while-loop) combined with `.substring` extraction is significantly faster (~2x or more) than memory-heavy line-by-line splitting (`split('\n')`) and character-by-character string building.
**Action:** When extracting sub-strings or searching large documents (like compiling or parsing LaTeX), use regex over string splitting, and prefer `substring` over building result strings inside loops. Track line numbers lazily using `String.prototype.indexOf('\n', lastIndex)` on the original string rather than splitting the entire text into lines just to count them.
