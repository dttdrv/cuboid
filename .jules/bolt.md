## 2024-03-06 - Replacing split('\\n') with Global Regex + Substring
**Learning:** For heavy text parsing (like extracting sections from large LaTeX files), splitting the entire string by newlines (`split('\\n')`) and running multiple regexes on each line creates significant CPU overhead and array allocations. Using a single-pass global regular expression (`exec` with `/g`) over the entire document and counting newlines efficiently using `indexOf` improved parsing speed by over 3x. Furthermore, iterating directly over the string and using `.substring` instead of building strings character-by-character (`result += char`) also reduces intermediate string allocations.
**Action:** Always prefer single-pass global regular expressions and `substring` extraction over line-by-line splitting and character-by-character string building for heavy text parsing in this codebase to minimize CPU overhead and array allocations.
